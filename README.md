# Personal Portfolio - Assignment 3

## Description

This project is a personal portfolio website created for SWE 363 Web Engineering at KFUPM.

Assignment 3 builds on my previous portfolio assignments by adding external API integration, project sorting, and further improvements to the website. The website includes an About Me section, two previous projects, a contact form, responsive design, and light/dark mode.

## Features

- About Me section
- Projects section showcasing two previous projects
- Project filtering using a dropdown menu
- Project sorting using A-Z and Z-A
- External API integration to display the current date
- Contact form with HTML validation and success feedback
- Light and dark mode
- Theme preference saved using `localStorage`
- Responsive design for desktop and mobile devices
- Navigation links with smooth scrolling

## Technologies Used

- HTML
- CSS
- JavaScript
- `localStorage`
- External API

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional installation or dependencies are required.
